## 남은 편차와 비범위

- 번역은 최종 3회 모두 `output_length_exceeded: 1`, 계획 배치 4개 대비 실제 호출 6회. 재시도 비용이 아직 남아 있음.
- 임상 `repair_count=0`이어도 구조 복구는 5/7/6건 있었으며, 후보 참조 의미 검증까지 모두 통과한 것은 아님.
- 미배정 Fact 수는 3/4/3. 공통 항목은 부친 심근경색, ST분절 하강, 통증 호전. 2회차는 심장내과 병동 입원 세부정보도 미배정.
- 가족력/검사 결과의 신규 기록 위치를 임의로 결정하지 않음. 통증 호전의 기존 HPI 미반영도 숨기지 않고 검토 한계로 남김.
- 12개 필드 유지. 미반영 UI 목록 유지. 자동 임상 보완·선택 재작성·추가 필드·전역 번역 캐시·토큰 예산 변경 없음.
- 이 한 개 합성 대화로 전체 의료 대화의 품질, 위험 신호 검출률, 미언급/부정/상충의 모든 조합을 보증할 수 없음.
